# Agent gotchas (mirrored)

## Browser must stay open

**Wrong:** Close headed Chromium/Chrome or IDE browser when the user is supposed to watch.  
**Right:** Leave browser open; narrate on Canvas; user reviews workflow.

## Gate before create return API

**Wrong:** Keep POSTing create when form version / entity / reporting date is not available.  
**Right:** Stop; short clear message; offer assign form **or** use available version; report activation start/end; ask user to pick date.
